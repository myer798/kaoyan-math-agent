$$f_{xy}'' = \frac{\partial}{\partial y}\left[e^x\left(2x^2 - y^2 + 4x\right)\right] = -2ye^x \text{——5 分}$$

$$f_{yy}'' = \frac{\partial}{\partial y}\left(-2ye^x\right) = -2e^x \text{——6 分}$$

④ 在驻点 $(0,0)$ 和 $(-2,0)$ 分别判别

计算在 $(0,0)$ 的二阶偏导值

$$A = f_{xx}''(0,0) = e^0[0 - 0 + 0 + 4] = 4$$

$$B = f_{xy}''(0,0) = -2 \cdot 0 \cdot e^0 = 0$$

$$C = f_{yy}''(0,0) = -2e^0 = -2$$

计算判别式 $\Delta = AC - B^2 = 4 \times (-2) - 0^2 = -8 < 0$，所以点 $(0,0)$ 不是极值点——7 分

计算在 $(-2,0)$ 的二阶偏导值

$$A = f_{xx}''(-2,0) = e^{-2}\left[2(4) - 0 + 8(-2) + 4\right]$$
$$= e^{-2}[8 - 16 + 4] = e^{-2}(-4) = -\frac{4}{e^2}$$

$$B = f_{xy}''(-2,0) = -2 \cdot 0 \cdot e^{-2} = 0$$

$$C = f_{yy}''(-2,0) = -2e^{-2} = -\frac{2}{e^2}$$

计算判别式 $\Delta = AC - B^2 = \left(-\frac{4}{e^2}\right)\left(-\frac{2}{e^2}\right) - 0 = \frac{8}{e^4} > 0$

因为 $AC - B^2 > 0$ 且 $A < 0$，所以点 $(-2,0)$ 是极大值点——9 分

又因为 $f(-2,0) = [2(4) - 0]e^{-2} = 8e^{-2} = \frac{8}{e^2}$

所以 $f(x,y) = (2x^2 - y^2)e^x$ 的极大值为 $\frac{8}{e^2}$——10 分
