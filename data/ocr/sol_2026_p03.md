A. $A^*$ 是置换矩阵  
B. $A^{-1}$ 是置换矩阵  
C. $A^{-1} = A^*$  
D. $A^{-1} = -A^*$

【答案】B

【解析】不妨设 $A = E_{12}^n$，$E_{12}$ 表示交换 $E$ 的 1,2 两行，注意到 $E_{12}E_{12} = E, |E_{12}| = -1$，于是
$$
A =
\begin{cases}
E & n = 2k \\
E_{12} & n = 2k - 1
\end{cases}
\quad (k = 1,2,\cdots), \quad
A^{-1} =
\begin{cases}
E & n = 2k \\
E_{12} & n = 2k - 1
\end{cases}
$$
故 $A^{-1}$ 为置换矩阵，$A^* = |A|A^{-1} =
\begin{cases}
E & n = 2k \\
-E_{12} & n = 2k - 1
\end{cases}$，故选 B

6. 设 $A, B$ 是 $n$ 阶矩阵，$\beta$ 为 $n$ 维列向量，且 $A$ 的列向量组可由 $B$ 列向量组线性表示，则（　　）

A. 若 $Ax = \beta$ 有解，则 $Bx = \beta$ 一定有解  
B. 若 $A^Tx = \beta$ 有解，则 $B^Tx = \beta$ 一定有解  
C. 若 $Bx = \beta$ 有解，则 $Ax = \beta$ 一定有解  
D. 若 $B^Tx = \beta$ 有解，则 $A^Tx = \beta$ 一定有解

【答案】A

【分析】$A$ 的列向量组可由 $B$ 的列向量组线性表示，即 $\exists C$，使得 $A = BC$

【解析】方法一：选项 A：$Ax = \beta$ 有解 $\Rightarrow \beta$ 可由 $A$ 列向量表示，而 $\beta$ 都能被 $A$ 表示，更可以被 $B$ 的列表示，即 $Bx = \beta$ 有解

选项 BD：题目给的列向量的关系推不出行向量关系

选项 C：大范围推不出小范围

方法二：举反例

① $A =
\begin{pmatrix}
0 & 0 \\
0 & 0
\end{pmatrix},
B =
\begin{pmatrix}
1 & 0 \\
0 & 1
\end{pmatrix}$，取 $\beta =
\begin{pmatrix}
1 \\
1
\end{pmatrix}$，排除 C 选项

② $A =
\begin{pmatrix}
0 & 1 \\
0 & 0
\end{pmatrix},
B =
\begin{pmatrix}
1 & 0 \\
0 & 0
\end{pmatrix}$，$A^T =
\begin{pmatrix}
0 & 0 \\
1 & 0
\end{pmatrix},
B^T =
\begin{pmatrix}
1 & 0 \\
0 & 0
\end{pmatrix}$

取 $\beta =
\begin{pmatrix}
0 \\
1
\end{pmatrix}$，排除 B 选项；取 $\beta =
\begin{pmatrix}
1 \\
0
\end{pmatrix}$，排除 D 选项
