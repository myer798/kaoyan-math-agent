【解析】由于 $\alpha_1, \alpha_2$ 线性无关，$\alpha_1, \alpha_2, \alpha_3$ 线性相关，则 $\alpha_3$ 可由 $\alpha_1, \alpha_2$ 线性表示。又因为  
$\alpha_1 + \alpha_2 + \alpha_4 = 0$，则 $\alpha_4$ 可由 $\alpha_1, \alpha_2$ 线性表示，于是 $r(\alpha_1, \alpha_2, \alpha_3) = r(\alpha_1, \alpha_2, \alpha_3, \alpha_4) = 2$，  
所以方程组 $x\alpha_1 + y\alpha_2 + z\alpha_3 = \alpha_4$ 表示一条直线。  

当 $(x, y, z)^\mathrm{T} = (0, 0, 0)^\mathrm{T}$ 时，则 $\alpha_4 = 0$，于是 $\alpha_1 + \alpha_2 = 0$，这与 $\alpha_1, \alpha_2$ 线性无关矛盾。所以  
$(0, 0, 0)^\mathrm{T}$ 不是方程的解，故方程组 $x\alpha_1 + y\alpha_2 + z\alpha_3 = \alpha_4$ 不过原点。  

故答案选 D。  

7. 设 $n$ 阶矩阵 $A, B, C$ 满足 $r(A) + r(B) + r(C) = r(ABC) + 2n$，给出下列四个结论：  

① $r(ABC) + n = r(AB) + r(C)$；  
② $r(AB) + n = r(A) + r(B)$；  
③ $r(A) = r(B) = r(C) = n$；  
④ $r(AB) = r(BC) = n$，  

其中正确结论的序号是  
A. ①②．  
B. ①③．  
C. ②④．  
D. ③④．  

【答案】A．  

【解析】因为 $r(ABC) \geq r(AB) + r(C) - n$, $r(AB) \geq r(A) + r(B) - n$，所以  
$$
r(ABC) \geq r(A) + r(B) + r(C) - 2n.
$$  
又因为 $r(A) + r(B) + r(C) = r(ABC) + 2n$，所以  
$$
r(ABC) + n = r(AB) + r(C),\quad r(AB) + n = r(A) + r(B).
$$  
故答案选 A．  

8. 设二维随机变量 $(X, Y)$ 服从正态分布 $N(0, 0; 1, 1; \rho)$，其中 $\rho \in (-1, 1)$。若 $a, b$ 为满足 $a^2 + b^2 = 1$ 的任意实数，则 $D(aX + bY)$ 的最大值为  

A. 1．  
B. 2．  
C. $1 + |\rho|$．  
D. $1 + \rho^2$．  

【答案】C．  

【解析】  
$$
D(aX + bY) = a^2 DX + b^2 DY + 2ab \operatorname{Cov}(X, Y)
$$
$$
= a^2 DX + b^2 DY + 2ab\rho\sqrt{DX}\sqrt{DY} = a^2 + b^2 + 2ab\rho = 1 + 2ab\rho.
$$  
因为 $a^2 + b^2 = 1$，所以 $2|ab| \leq a^2 + b^2 = 1$，故 $D(aX + bY)$ 的最大值为 $1 + |\rho|$．  

故答案选 C．
