17. (本题满分 10 分)

设曲线 $ y = y(x) (x > 0) $ 经过点 $ (1,2) $，该曲线上任一点 $ P(x,y) $ 到 $ y $ 轴的距离等于该点处的切线在 $ y $ 轴上的截距。

(1) 求 $ y(x) $；

(2) 求函数 $ f(x) = \int_1^x y(t)\,\mathrm{d}t $ 在 $ (0,+\infty) $ 上的最大值。

【解】(1) 曲线上任一点 $ P(x,y) $ 处的切线方程为 $ Y = y'(x)(X - x) + y $，在 $ y $ 轴截距为 $ y(x) - x y'(x) $，点 $ P(x,y) $ 到 $ y $ 轴的距离为 $ x $，即 $ y(x) - x y'(x) = x $，为一阶齐次微分方程，化简得 $ y'(x) - \frac{1}{x}y(x) = -x $，故：

$$
y(x) = e^{\int \frac{1}{x}\,\mathrm{d}x} \left( \int -e^{-\int \frac{1}{x}\,\mathrm{d}x} \,\mathrm{d}x + C \right) = x \left( \int -\frac{1}{x}\,\mathrm{d}x + C \right) = x(C - \ln x)
$$

又曲线 $ y = y(x) $ 经过点 $ (1,2) $，所以有 $ C = 2 $，故 $ y(x) = x(2 - \ln x) $。

(2) 令 $ f'(x) = y(x) = 0 $，解得：$ x = e^2 $，当 $ 0 < x < e^2 $ 时，$ f'(x) > 0 $，$ f(x) $ 单调递增；当 $ x > e^2 $ 时，$ f'(x) < 0 $，$ f(x) $ 单调递减，故当 $ x = e^2 $ 时，函数 $ f(x) $ 取得最大，最大值为：

$$
f(e^2) = \int_1^{e^2} t(2 - \ln t)\,\mathrm{d}t = \frac{1}{4}e^4 - \frac{5}{4}.
$$

□

18. (本题满分 12 分)

求函数 $ f(x,y) = (y - x^2)(y - x^3) $ 的极值。

【解】由 $ f(x,y) = (y - x^2)(y - x^3) $ 知：
$$
\begin{cases}
f_x'(x,y) = x(5x^3 - 3xy - 2y) \\
f_y'(x,y) = 2y - x^3 - x^2
\end{cases}
$$
，令 $ f_x(x,y) = f_y(x,y) = 0 $，解得
$$
\begin{cases}
x = 0 \\
y = 0
\end{cases},
\quad
\begin{cases}
x = 1 \\
y = 1
\end{cases},
\quad
\begin{cases}
x = \dfrac{2}{3} \\
y = \dfrac{10}{27}
\end{cases}
$$

求二阶偏导有：
$$
\begin{cases}
f_{xx}''(x,y) = -6xy - 2y + 20x^3 \\
f_{xy}''(x,y) = -3x^2 - 2x \\
f_{yy}''(x,y) = 2
\end{cases}
$$

对于点 $ (0,0) $，$ A = 0, B = 0, C = 2, AC - B^2 = 0 $，当 $ 0 < x < 1 $ 时，在 $ x^3 < y < x^2 $ 内，$ f(x,y) < 0 $，在 $ y > x^2 $ 内，$ f(x,y) > 0 $，则 $ f(0,0) = 0 $ 不取极值；

对于点 $ (1,1) $，$ A = 12, B = -5, C = 2, AC - B^2 < 0 $，不是极值点；

对于点 $ \left( \dfrac{2}{3}, \dfrac{10}{27} \right) $，$ A = \dfrac{100}{27}, B = \dfrac{24}{9}, C = 2, AC - B^2 = \dfrac{24}{81} > 0 $，是极小值点，故存在极小值 $ f\left( \dfrac{2}{3}, \dfrac{10}{27} \right) = -\dfrac{4}{729} $。

□
