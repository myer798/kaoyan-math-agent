1. 曲线 $ y = x \ln \left( e + \frac{1}{x - 1} \right) $ 的斜渐近线方程为  
　　(A) $ y = x + e $  
　　(B) $ y = x + \frac{1}{e} $  
　　(C) $ y = x $  
　　(D) $ y = x - \frac{1}{e} $

解．由于  
$$
k = \lim_{x \to \infty} \frac{y}{x} = \lim_{x \to \infty} \frac{x \ln \left( e + \frac{1}{x - 1} \right)}{x} = \lim_{x \to \infty} \ln \left( e + \frac{1}{x - 1} \right) = 1
$$
$$
b = \lim_{x \to \infty} (y - x) = \lim_{x \to \infty} \left[ x \ln \left( e + \frac{1}{x - 1} \right) - x \right]
$$
$$
= \lim_{x \to \infty} x \left[ \ln \left( e + \frac{1}{x - 1} \right) - 1 \right] = \lim_{x \to \infty} x \left[ \ln \left( e + \frac{1}{x - 1} \right) - \ln e \right]
$$
$$
= \lim_{x \to \infty} x \ln \left[ 1 + \frac{1}{e(x - 1)} \right] = \lim_{x \to \infty} \frac{x}{e(x - 1)} = \frac{1}{e}.
$$

则斜渐近线方程为：$ y = x + \frac{1}{e} $，故选 (B).  
□

2. 若微分方程 $ y'' + a y' + b y = 0 $ 的解在 $ (-\infty, +\infty) $ 上有界，则  
　　(A) $ a < 0, b > 0 $  
　　(B) $ a > 0, b > 0 $  
　　(C) $ a = 0, b > 0 $  
　　(D) $ a = 0, b < 0 $

解．若 $ r^2 + a r + b = 0 $ 有实根，则通解为：$ C_1 e^{r_1 x} + C_2 e^{r_2 x} $ 或 $ (C_1 + C_2 x) e^{r_1 x} $，此时，$ r \ne 0 $ 时，$ e^{r x} $ 必无界，$ r = 0 $ 时，$ x e^{r x} $ 必无界，则 $ r^2 + a r + b = 0 $ 必有虚根，即 $ r_{1,2} = \alpha \pm \beta i $，则通解为：$ e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x) $，要使其有界，则 $ \alpha = 0 $，即 $ a = 0 $，则 $ b > 0 $，故选 (C).  
□

3. 设函数 $ y = f(x) $ 由  
$$
\begin{cases}
x = 2t + |t| \\
y = |t| \sin t
\end{cases}
$$
确定，则  
　　(A) $ f(x) $ 连续，$ f'(0) $ 不存在  
　　(B) $ f'(0) $ 存在，$ f'(x) $ 在 $ x = 0 $ 处不连续  
　　(C) $ f'(x) $ 连续，$ f''(0) $ 不存在  
　　(D) $ f''(0) $ 存在，$ f''(x) $ 在 $ x = 0 $ 处不连续

解．当 $ t > 0 $ 时，$ x > 0 $，此时  
$$
\begin{cases}
x = 3t \\
y = t \sin t
\end{cases}, \quad \frac{dy}{dx} = \frac{\sin t + t \cos t}{3};
$$

当 $ t < 0 $ 时，$ x < 0 $，此时  
$$
\begin{cases}
x = t \\
y = -t \sin t
\end{cases}, \quad \frac{dy}{dx} = -\frac{\sin t + t \cos t}{1};
$$

当 $ t = 0 $ 时，$ x = 0 $，  
$$
f'(0) = \lim_{x \to 0} \frac{f(x) - f(0)}{x} = \lim_{t \to 0} \frac{|t| \sin t}{2t + |t|} = 0,
$$

由于 $ f'(0) = \lim_{x \to 0^+} f'(x) = \lim_{x \to 0^-} f'(x) = 0 $，所以 $ f'(0) $ 在 $ x = 0 $ 处连续，所以 $ f'(0) $ 连续。而：

$$
f'_+(0) = \lim_{x \to 0^+} \frac{f'(x) - f'(0)}{x} = \lim_{t \to 0^+} \frac{\sin t + t \cos t}{9t} = \frac{2}{9},
$$
$$
f'_-(0) = \lim_{x \to 0^-} \frac{f'(x) - f'(0)}{x} = \lim_{t \to 0^-} \left( -\frac{\sin t + t \cos t}{t} \right) = -2.
$$
