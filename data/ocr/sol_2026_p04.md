8. 设随机变量 $ X \sim N(1, 2) $，$ f(t) = E\left[(X + t)^2\right] $，则 $ f(t) $ 的最小值点和最小值分别为（　　）

A. 1, 2　　B. 1, 4　　C. -1, 2　　D. -1, 4

【答案】C

【解析】① $ X \sim N(1, 2) \Rightarrow E(X) = 1, D(X) = 2 $

② $ E(X^2) = D(X) + E^2(X) = 2 + 1 = 3 $

③ $ f(t) = E(X^2 + 2tX + t^2) = E(X^2) + 2tE(X) + t^2 = t^2 + 2t + 3 = (t + 1)^2 + 2 $

当 $ t = -1 $ 时取得最小值，最小值为 2

9. 设随机变量 $ X $ 的分布函数为 $ F(X) $，$ Y $ 的分布函数为 $ F(a y + b) $，$ E(X) = \mu $，$ D(X) = \sigma^2 (\sigma > 0) $，$ E(Y) = 0 $，$ D(Y) = 1 $，则（　　）

A. $ a = \sigma, b = \mu $　　B. $ a = \sigma, b = -\mu $　　C. $ a = \dfrac{1}{\sigma}, b = \mu $　　D. $ a = \dfrac{1}{\sigma}, b = -\mu $

【答案】A

【解析】① 令 $ Y = \dfrac{X - \mu}{\sigma} $

② $ F_Y(y) = P\{Y \leqslant y\} = P\left\{\dfrac{X - \mu}{\sigma} \leqslant y\right\} = P\{X \leqslant \sigma y + \mu\} $

即 $ F_Y(y) = F(\sigma y + \mu) $ 与题目中 $ F(a y + b) $ 对应，则 $ a = \sigma, b = \mu $
